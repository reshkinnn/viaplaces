# viaplaces

Мини-сервис для прогулки после встречи: выбираешь станцию метро и видишь красивые места и двери Петербурга, отсортированные по времени пешком.

## Как открыть

Файл `index.html` самодостаточный. Его можно открыть двойным кликом или выложить на GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

## Что внутри

- Выбор станции (16 станций) и фильтры настроения: поесть, погулять, пофоткаться, погреться.
- Места сгруппированы по времени пешком: до 10 минут и более 10 минут. Время считается по координатам.
- Избранное: «Хочу сходить» и «Были». Хранится в браузере (`localStorage`).
- Форма «Предложить место» и кнопка «Закрылось?». Пока данные остаются только на устройстве пользователя.

## Фото

У каждой карточки есть место под фото. Пока фото нет, показывается цветная заглушка с первой буквой названия.

Чтобы добавить фото, положите файл в папку `photos/` и назовите его по `id` места: `photos/doris-local.jpg`. Больше ничего менять не нужно. Подойдёт горизонтальный снимок примерно 1200×750 px, до 200 КБ. Используйте свои фото или снимки, на которые у вас есть разрешение заведения.

## Где править данные

В `index.html` найдите массивы `STATIONS` и `PLACES`. У места есть поля:

| Поле | Значение |
| --- | --- |
| `id` | уникальный код |
| `name`, `addr`, `desc` | название, адрес, короткое описание |
| `moods` | `sit` (поесть), `walk`, `photo`, `warm` |
| `lat`, `lon` | координаты |
| `note` | необязательная пометка (например, «Красивая дверь» или «с 18:00») |
| `q` | запрос для кнопки «На карте» |

## Что проверить перед запуском

- Адреса и координаты найдены автоматически, их нужно сверить с картой.
- Часы работы и актуальность заведений нужно проверить вручную.
- Парадные находятся в жилых домах, поэтому снимать их нужно из-за закрытой двери.
